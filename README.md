# Sense Ruler（感知直尺）

> 一个"输入校准型解谜"小游戏：森林里一个人、一根可变长的棍子，马里奥式连续旅途。
> 玩家从头到尾只会一个操作——**按住放绳、松手定长**；棍子变成什么形状（折、弯、圈）由情境自动决定。

## 一句话 Fun Hypothesis

**玩家用唯一一个"调棍长"的操作，反复撞上自己"对长度只有定性、没有定量概念"的认知死角——每次"差一点"都不是失误，而是人类感知的必然，于是"笑着再试一次"成了最上头的循环。**

支撑事实：人对长度的感知是 ordinal（能比大小）而非 cardinal（给不出数值）；即使看到"差一截"的反馈，也无法在下一次定量复现；所以单次误差不随练习消失，每关都是新决策。

## Design Pillars（5 条，后续所有设计过审标尺）

| # | Pillar | 一句话 |
|---|---|---|
| P1 | 操作不变，只调总长 | 变形（角度/比例/折点）全部情境写死，第二个决策维度一律拒 |
| P2 | 定性不定量，失败只告知不教学 | 反馈给相对/位置信息（鬼影、差一截），不给刻度数值 |
| P3 | 情境自明，变形由场景说出 | 以空间几何自明为主，允许少量非数值文字补强；遮掉文字 3 秒要能看懂 |
| P4 | 难度来自新盲点，不来自新形状 | 每关撞上的"搞不准的是哪种长度"必须是新的 |
| P5 | 判定宽松、表现永远正确 | 容差按人类误差设，成功瞬间 snap 到理想形；未过 σp 验证不锁终值 |

## 内容四分类（难度主轴）

| 类 | 形态 | 感知失败 |
|---|---|---|
| 朝向 | 单根直线换角度 | 朝向估长盲（线转角度标尺飘） |
| 折线 | 尖角折线 | 分段求和盲（忘翻倍 / 不累加各段） |
| 曲线 | 平滑弧线/螺旋 | 弧弦盲（按弦长低估弧长）、螺旋藏线 |
| 闭合 | 首尾封口轮廓 | 周长换算盲（拿外接尺寸当代周长） |

跨类宏观序：**朝向 < 折线 < 曲线 < 闭合**（可见锚点递减 / 隐藏量递增），允许边界交叉。
路线：**A · snackable**，单局 3–5 分钟，每情境 15–30 秒，一局 10–15 情境，总内容 20–40 分钟跨会话。

## 工具用法

- **推容差**：改 `sense_ruler_montecarlo.py` 顶部 `SCEN`（`sigma_p` / 手高 / 目标通过率），重跑即得各关推荐容差。
- **量 σp**：浏览器打开 `sigma_p_measure.html`（复用原型放绳手感、三形状、记忆/可见双条件）。找 20 人、每人每长度 ≥5 次；跑完看"记忆条件"CV% 均值，填进 `SCEN.sigma_p` 重跑定稿。
  - ⚠️ 本工具无微调阶段，测得的是"感知 + 松手延迟"总误差，填完后把 `MU_TAU/SD_TAU` 设近 0，避免重复计入。
  - 游戏是跨维度换算（高度→宽度、长度→周长），比工具的 1:1 呈现更难，建议再留 20–30% 余量 [PLACEHOLDER]。
